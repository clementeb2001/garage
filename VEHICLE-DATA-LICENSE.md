# Vehicle catalogue data

The make, model, generation and engine catalogue in `vehicle-catalog.js` is an
adapted extract of the
[`vehicle-makes-models`](https://github.com/gor3a/vehicle-makes-models)
database. Its upstream source is identified by that project as
[`autoevolution.com`](https://www.autoevolution.com/).

The database extract is available under the **Open Database License (ODbL)
1.0**: https://opendatacommons.org/licenses/odbl/1-0/

Changes made here: only makes currently represented in the Autoservice
Bettenduerf REMUS/DBA catalogue are retained; fields are compacted and renamed
for browser delivery. The extract is used exclusively to build the vehicle
selector. Product compatibility continues to come from the REMUS and DBA
supplier mappings and is verified before dispatch.
